# MK-Duo

App de calculadora gestacional para gestação gemelar, derivado do [MKCalc](https://github.com/morgckummer-debug/appcalcmk).

Neste momento o código é uma cópia do MKCalc original (idade gestacional, DPP, exames, monitoramento de peso, movimentos fetais e contrações) — a adaptação para gêmeos (corionicidade, dois bebês, discordância de peso, cronograma de exames condicional) ainda está por vir.

Protótipo de design das telas gemelares: `MKCalc Dupla`.
